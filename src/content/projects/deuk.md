## 프로젝트 소개

**deuk**은 developer와 sanghyuk을 합친 이름입니다. 풀스택 개발자 표상혁의 기술 글과 개인 프로젝트를 모으는 웹사이트입니다.

## 만들고자 하는 것

글을 편하게 작성하고 오랫동안 관리할 수 있는 구조를 목표로 합니다. 콘텐츠는 Markdown과 MDX 파일로 관리하고, 페이지는 빌드 시점에 생성합니다.

- **HOME**: 소개, 최근 글, 대표 프로젝트
- **POSTS**: 기술 글, 태그 필터, 검색
- **PROJECT**: 프로젝트 소개와 개발 기록
- **ABOUT**: 소개, 이력서, 연락처

## 기술 선택

| 기술 | 용도 |
| --- | --- |
| Astro | 정적 페이지 생성 |
| TypeScript | 타입 검사 |
| Markdown / MDX | 글과 프로젝트 작성 |
| Pagefind | 본문 검색 |
| CSS 변수 | 라이트·다크 테마 |

## 현재 진행 상태

현재 로컬에서 첫 번째 버전을 개발하고 있습니다. Git 연동과 Cloudflare 배포는 이후 진행할 예정입니다. 프로필 이미지, 이력서와 연락처는 준비한 뒤 추가합니다.

## 앞으로의 계획

실제 기술 글을 작성하며 읽기 경험을 다듬고, 운영 과정에서 필요한 기능을 추가합니다. 댓글은 이후 개발할 예정입니다.
